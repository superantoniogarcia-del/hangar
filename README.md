# HANGAR

Maqueta 3D explorable (versión jugable inicial) del pub Hangar, en Córdoba (Av. de la Libertad 2). Es de noche, Álvaro pincha en la cabina de DJ y tú llevas a Antonio.

**Jugar:** https://superantoniogarcia-del.github.io/hangar/

Controles: WASD/flechas para andar, Mayús para correr, arrastrar el ratón para girar la cámara, rueda para el zoom, C para cambiar la cámara. En el móvil: joystick a la izquierda y arrastrar a la derecha. Toca la pantalla para que suene la música.

Es un único archivo `index.html` (three.js 0.160 incluido). La distribución sigue el plano de forma aproximada.
